# Changelog

Notable public-project changes are recorded here. Entries describe this repository; measurements and verification results belong to the exact revision that produced them.

## v0.1.0-community — 2026-09-20

### Added

- Initial public source baseline for Living Empires: The Broken Accord in Unity 6000.6.0f1 with URP 17.7.0.
- First Winter Delivery economy chapter and the separate, prepared Toll War military scenario.
- Settlement and army controls, a minimap, recruitment, squad orders, upgrades, finite raids, and recovery.
- MIT license for original project code, documentation, and original project-generated art, with third-party license records retained separately.
- Contribution guidance, an initial roadmap, issue forms, a pull request template, and six published starter issues.
- Portable Windows release, build/test scripts, gameplay screenshots and a scoped validation record.

### Public edition

- Council presentation uses text. Earlier external-service voice recordings and portrait images are excluded.
- Machine-specific build history and private account records are excluded from the public project.
- Earlier private-build test counts and performance measurements are not presented as validation of this edition.
